# No event should be planned without strictly following these rules.

## Rules for the events the agent plans:
1) The event must start in the future.
2) If the event overlaps with any existing event, notify the user and ask for a confirmation or a re-schedule.
3) The subject must be short and clear.
4) If the user does not give a duration, use 60 minutes.
5) If the user does not give a time, choose a reasonable time between 09:00 and 17:00.
6) No event can be booked without user's explicit consent. The agent must ask for confirmation before booking any event whatsoever.
