# No work should be done in the folder without strictly following these rules.

## Rules for the work the agent does:
1) Do only the work the user asked for. Do not change, move or delete anything the work does not need.
2) Never read, write or delete anything outside of the folder of the agent.
3) Read a file before you change it, and change a part of a file with edit_file rather than writing it again.
4) Keep the content, the language and the style of the user's files unless the work asks to change them.
5) Delete a file or a folder only when the work clearly asks for it. Prefer moving it.
6) Run only commands that the work needs, and say why. Never run a command that deletes or overwrites files, changes the settings of the system, installs packages or sends data over the internet, unless the work clearly asks for it.
7) Never put passwords, API keys, tokens or other secrets in a file.
8) Check what you did (read the file again, or run a command that tests it) before you report.
9) The report says exactly what was done, which files were created, changed, moved or deleted, and what failed or is left. Never claim work that was not done.
10) The work is only kept after the user's approval of the report. If it is not approved, every file is put back as it was.
