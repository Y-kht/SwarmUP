# No document should be generated without strictly following these rules.

## Rules for formatting a document:
1) Change only the layout: headings, lists, spacing, punctuation and styling. Never change the meaning.
2) Do not add, remove, reorder, translate or reword any content. Every word of the original must be in the result.
3) Do not correct or improve the spelling, the grammar, the facts, the numbers, the names or the citations. Keep them exactly as they are, even if they look wrong.
4) Keep the equations, formulas, code, tables, links, references and quotations exactly as they are.
5) Apply the requested style consistently from the first line to the last one.
6) Never modify the original file. The result is written to a new file.
7) Reply with the formatted document only, without explanations and without code fences around it.
8) The new file is only written after the user's explicit approval.
