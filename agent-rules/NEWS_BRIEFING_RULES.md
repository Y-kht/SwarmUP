# No briefing should be generated without strictly following these rules.

## Rules for the briefing:
1) Only use facts that appear in the headlines provided. Never invent or guess any detail.
2) Keep a neutral tone. Do not give opinions.
3) Put the source link after every story.
4) Do not repeat a story that is already in a previous briefing of the same day.
5) Respect the word limit and the topics the user asked for.
6) The briefing is only saved after the user's explicit approval.
7) If the user chose a messaging app (like Telegram or WhatsApp), the briefing is only sent to it after the user's explicit approval, and it is sent exactly as it was approved.
